# Implementation Plan: Audio Overview

**Branch**: `010-audio-overview` | **Date**: 2026-03-09 | **Spec**: [GitHub #10](https://github.com/pverge2112/plaudeLM/issues/10)
**Input**: `specs/010-audio-overview/spec.md`

## Summary

Implement the `POST /audio-overview` FastAPI endpoint and the `query/audio.py` orchestration module that generates a grounded podcast-style script (host + guest dialogue) using top-K Qdrant chunks + gpt-4o-mini via Kong, then synthesizes a WAV audio file using `pyttsx3` + `espeak-ng` (local, CPU-only, no GPU).

The `audio_overview` MCP tool in `mcp/src/tools/audio.ts` is already complete and calls this endpoint — no MCP-side changes required.

---

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**: FastAPI, Pydantic v2, httpx, qdrant-client, pyttsx3, espeak-ng (system)
**Storage**: Docker named volume `audio_data` mounted at `AUDIO_OUTPUT_DIR` (env var)
**Testing**: pytest (unit + integration), Jest (MCP contract + integration)
**Target Platform**: Linux (Docker container, headless, CPU-only)
**Project Type**: Web service (FastAPI endpoint addition)
**Performance Goals**: End-to-end `< 120s` (Qdrant embed + LLM script gen + TTS synthesis)
**Constraints**: WAV output only (MVP); no GPU; no external TTS API; file path returned (no streaming)
**Scale/Scope**: Single user, home lab, one audio file per call

### Phase 2 — Green (Implementation)

Implement in dependency order:

1. `query/models.py` — add `AudioOverviewRequest`, `AudioOverviewResponse`
2. `query/config.py` — add `audio_output_dir: str` field; validate dir exists (create if missing)
3. `query/audio.py` — `AudioGenerator` class:
   - `_embed_topic()` — calls Kong `/plaudelm/embed`
   - `_search_chunks()` — Qdrant cosine search, raises 404 if empty
   - `_generate_script()` — calls Kong `/plaudelm/chat` with podcast prompt
   - `_synthesize_wav()` — pyttsx3 engine, `engine.save_to_file()`, runs in thread executor
   - `_compute_duration()` — `wave.open()` → frames / framerate
   - `generate()` — orchestrates all steps
4. `query/main.py` — add `POST /audio-overview` endpoint; wire `AudioGenerator`
5. `query/requirements.txt` — add `pyttsx3`
6. `query/Dockerfile` — add `espeak-ng libespeak-ng1` apt packages
7. `docker-compose.yml` — add `AUDIO_OUTPUT_DIR`, `audio_data` volume
8. `.env.example` — add `AUDIO_OUTPUT_DIR=/data/audio`
